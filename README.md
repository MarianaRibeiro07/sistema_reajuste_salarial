Sistema de Reajuste Salarial – Tech Solutions
📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma interface web onde o gestor pode inserir os dados de um colaborador para calcular um possível reajuste salarial.

O sistema aplica regras de negócio específicas baseadas no cargo do funcionário e no critério de mérito, validando automaticamente se o colaborador tem direito ao aumento.

🎯 Objetivo da Atividade

Praticar conceitos fundamentais de JavaScript, aplicando:

✅ Operadores de Atribuição

✅ Operadores Aritméticos

✅ Operadores Lógicos (&&)

✅ Template Literals (crase ` `)

✅ Manipulação de dados via interface web

🏢 Regras de Negócio
1️⃣ Cálculo por Cargo

O reajuste varia de acordo com o cargo:

Cargo	Percentual de Reajuste
Aprendiz	0%
Analista de TI	10%
Gerente de TI	15%
Diretor de TI	20%
2️⃣ Critério de Mérito (Regra de Ouro)

O reajuste somente será concedido se o colaborador atender ao seguinte critério:

✔️ 0 faltas

✔️ 0 atrasos nos últimos 365 dias

🔒 Caso o funcionário tenha faltas ou atrasos, o sistema:

Bloqueia o aumento

Exibe uma mensagem orientando o colaborador a procurar o RH
